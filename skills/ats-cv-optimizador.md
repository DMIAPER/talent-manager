# ATS CV Optimizer

## Summary
Evaluates a candidate's resume against a specific job description to optimize it for ATS filters, identifying missing keywords and crafting quantified STAR-method bullet points using real experience.

## When to Use
Use when the user provides a job offer alongside their real experience and asks to optimize their CV, find missing keywords, or generate tailored bullet points.

## Steps

1. **Analyze Inputs:** Read and analyze the provided job offer and the user's real experience data. 
2. **Identify Keyword Gaps:** 
   - Extract a list of **5 hard skills** and **3 soft skills** critical to the job offer that are missing or underrepresented in the user's provided experience.
3. **Draft STAR Bullet Points:** 
   - Write **3 high-impact bullet points** for the user's CV using the **STAR Method** (Situation, Task, Action, Result).
   - Ensure results are quantified where possible using data from the user's input.

## Guidelines
- **Strictly No Fabrication:** Never invent, assume, or fabricate experiences, metrics, or technical skills not present in the user's input.
- **ATS Friendly:** Focus on precise terminology and keyword alignment matching standard Applicant Tracking System algorithms.
- **Clear Formatting:** Present the output clearly separated into keyword analysis and STAR bullet points.
