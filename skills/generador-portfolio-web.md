# Web Portfolio Generator

## Summary
Analyzes a candidate's resume to design and generate a complete, responsive, and elegant HTML web portfolio featuring dark aesthetics, clear copywriting, and structured professional sections.

## When to Use
Use when the user provides a CV or professional experience data and asks to create a web portfolio, personal landing page, or HTML showcase.

## Steps

1. **Analyze Resume Data:** Extract and categorize the user's profile, specialization, experience, hard/soft skills, education, projects, and achievements.
2. **Structure the Content Strategy:** Translate raw CV data into engaging, credibility-driven personal branding copy (avoiding a dry, direct copy-paste approach).
3. **Design Layout & Aesthetics:** 
   - Apply a modern, elegant dark theme with subtle, professional accent colors.
   - Ensure responsive design principles (desktop, tablet, and mobile compatibility).
4. **Organize Sections:** Structure the web architecture into:
   - **Presentación (Hero):** Strong value proposition and headline.
   - **Sobre mí (About):** Professional background and personality overview.
   - **Experiencia (Experience):** Career history with impact-driven phrasing.
   - **Habilidades (Skills):** Concrete, realistic competency breakdown.
   - **Proyectos y logros (Projects & Achievements):** Highlighted milestones.
   - **Formación (Education):** Academic and certifications summary.
   - **Contacto (Contact):** Call-to-action and communication channels.
5. **Generate Output:** Deliver a clean, self-contained, and functional HTML file code structure.

## Guidelines
- **Strictly No Fabrication:** Base all portfolio content exclusively on the user's provided CV data without inflating metrics or inventing skills.
- **Responsive Code:** Use modern CSS (Flexbox/Grid) to guarantee cross-device adaptability.
- **Aesthetic Standards:** Keep the visual hierarchy clean, polished, and professional.
