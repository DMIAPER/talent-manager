# Video Resume Director

## Summary
Generates a structured, scene-by-scene cinematic script (7 to 10 scenes, 8-10 seconds per scene) featuring an avatar interacting dynamically with holographic UI elements, tailored to the user's professional profile and achievements.

## When to Use
Use when the user provides their professional role, sector, and key achievements to create a dynamic video resume script or AI-driven promotional spot.

## Steps

1. **Analyze Profile Data:** Review the provided professional profile, sector, and key achievements to extract core value propositions.
2. **Structure the Narrative:** Design a 7-to-10-scene cinematic arc (roughly 8-10 seconds per scene) blending professional storytelling with futuristic visual interactions (holographic cards, software UI activation, stage movement).
3. **Generate the Scene Table:** Produce a detailed breakdown table containing:
   - **Escena / Duración** (Scene number and seconds)
   - **Narración Voz en Off** (Voiceover script)
   - **Escenario** (Setting / Environment)
   - **Ángulo de Cámara** (Camera angle and movement)
   - **Acción del Avatar** (Avatar behavior on stage)
   - **Elementos Gráficos e Interacción Visual** (Holographic UI / graphic elements)

## Guidelines
- Maintain a visionary, professional, and engaging tone suitable for high-impact personal branding.
- Ensure technical actions match modern software and workspace metaphors.
- Keep pacing consistent with short, impactful video formats (approx. 1 minute to 1 minute and 30 seconds total).
